# 小白看这里

这是给零基础用户看的 Galcode 新手手册。本项目采取 MIT 协议分发，使用时不必通知我，各位玩的开心，做出更有意思的二创就好。

先说人话：Galcode 是一个装在终端里的 AI 二创工作室。你跟它说一句中文脑洞，它跟你讨论剧情、写好剧本、编译成 WebGAL 工程，然后给你一个网址——用浏览器打开就能看你的 MyGO 小剧场。你不用先学 WebGAL，也不用先成为命令行高手。

## 第一步：安装 Node.js

只需要装这一个东西。需要 Node.js 22.19 以上或 24 以上版本，直接装最新的 LTS 就行。

Windows：打开 PowerShell，运行：

```powershell
winget install OpenJS.NodeJS.LTS
```

macOS：

```bash
brew install node
```

Ubuntu / Debian：

```bash
sudo apt update
sudo apt install -y nodejs npm
```

（如果 apt 装的版本太老，去 nodejs.org 下载安装包，或者搜「nvm 安装 Node」。）

装完以后**关闭终端再重新打开**，然后检查：

```bash
node --version
```

看到 `v22.19.x` 或 `v24.x.x` 以上的版本号就行。

## 第二步：安装 Galcode

```bash
npm i -g galcode
```

## 第三步：启动

```bash
galcode
```

第一次运行会自动搭建环境（初始化 dsh profile、安装 TUI 组件），要跑一会儿，终端里刷很多字是正常的，不是坏了，是机器在努力把舞台搭起来。这一步需要联网。

## 第四步：填 API key

Galcode 用的是云端大模型（DeepSeek 官方接口），不需要你自己的电脑有显卡。第一次进入界面时会引导你填 API key，照着提示粘贴进去就行。之后想改，在界面里输入 `/login` 或 `/settings`。

API key 是你的私人物品，不要截图发群里！！据说祥爹当年就是这么欠下 169 亿的……

## 第五步：跟 AI 说你想做什么

直接用中文说人话，比如：

```text
我想写一个雨夜短篇，灯和爱音因为歌词理解不同吵了一下，但最后没有彻底说开
```

如果你脑子里只有一句「爱希牛逼」，也可以直接说，它会继续问你角色、口味和时长。

写主题的小技巧——好主题一般包含四样东西：

1. 谁登场。
2. 在哪里。
3. 有什么小冲突。
4. 结尾要甜一点、痛一点，还是怪一点。

比如：「爽世和睦，表面平静，实际都知道对方没有说真话，结尾留一点刺」。

## 第六步：看片

聊完以后它会自己校验、编译，然后启动预览。看到它打印出类似这样的网址：

```text
http://127.0.0.1:3000
```

复制到浏览器里打开，就能看到你的小剧场了。看完回到终端，让它停止预览（或者直接说「看完了」）。

写得不好就换主题，跑歪了就再来一次。小贴士：欲速则不达。（完了，全完了……）

## 常见问题

### Live2D 模型去哪弄？

公开版本**不会自带** Live2D runtime 和官方模型——这些是版权素材，不能二次分发。没有它们也能正常玩：画面里只有背景和文字，故事照跑。

想看完整 Live2D 效果：去作者 B 站账号看本项目介绍视频，按视频里的进群方式获取完整文件。拿到 runtime 文件后运行：

```bash
galcode cli install-live2d-runtime --from <文件所在目录>
```

模型压缩包放进 `figure` 素材目录即可，生成时会自动准备。拿到素材后请别重新打包公开上传——迷路可以，版权红线别迷路。

### 预览打不开 / 提示缺少 WebGAL 引擎？

WebGAL 引擎不随安装包附带，需要单独下载一次。先跑自检：

```bash
galcode doctor
```

如果它提示缺少 WebGAL 引擎，运行：

```bash
node "$(npm root -g)/galcode/scripts/galcode-bootstrap.mjs install"
```

装完再让它重新启动预览。如果浏览器打开了但画面空白、只有背景没有模型，多半是上一节的 Live2D 文件没补齐。

### doctor 怎么用？

```bash
galcode doctor
```

它就是体检：哪一行是 `[OK]` 就没问题，`[WARN]` 是可选项目（Live2D runtime、ffmpeg，缺了不影响核心流程），`[MISS]` 是必须修的。把完整输出发给会修电脑的人，事情就会从「它不动了」变成「它哪里不动了」。

### 想改模型 / 接口设置？

在 TUI 里输入 `/login` 或 `/settings`。模型配置全部归 dsh 管，不用手动编辑任何文件。

### `npm i -g` 报错权限不足（EACCES）？

macOS / Linux 上不要用 `sudo` 硬装，建议搜「npm 全局目录 改到用户目录」或用 nvm 管理 Node，一次配置终身免疫。
